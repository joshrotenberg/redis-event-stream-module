# Project links

The book explains how to use and operate Redis Event Stream. Repository-level
material stays beside the code:

- [Specification](https://github.com/joshrotenberg/redis-event-stream-module/blob/main/SPEC.md)
  defines the module's normative behavior.
- [Changelog](https://github.com/joshrotenberg/redis-event-stream-module/blob/main/CHANGELOG.md)
  records user-visible changes by release.
- [Contributing](https://github.com/joshrotenberg/redis-event-stream-module/blob/main/CONTRIBUTING.md)
  covers local development, testing, and pull requests.
- [Security policy](https://github.com/joshrotenberg/redis-event-stream-module/blob/main/SECURITY.md)
  explains how to report a vulnerability privately.
